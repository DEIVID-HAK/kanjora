# canjora
Kanjora es una plataforma de trueque de conocimiento: conecta programadores que necesitan inglés técnico con bilingües que quieren aprender desarrollo de software. Integra rutas de aprendizaje guiadas y un modelo de negocio con suscripciones VIP para emparejamiento prioritario y funciones prémium, escalable a más profesiones e idiomas.
